# lab_rust_fp

Семь задач лабораторной работы по функциональному программированию, выполненные на Rust.

## Запуск

Команды выполняются из каталога, содержащего `Cargo.toml`:

```bash
cargo run --bin task1
cargo run --bin task2
cargo run --bin task3
cargo run --bin task4
cargo run --bin task5
cargo run --bin task6
cargo run --bin task7 -- data/data_light.json
cargo test
```

При первой сборке Cargo загружает зависимости из crates.io. Файл `Cargo.lock` фиксирует их версии.

## Файлы

| Модуль | Задача |
| --- | --- |
| `src/field.rs` | Выборка одного или нескольких полей JSON |
| `src/gen_random.rs` | Ленивый генератор случайных целых чисел |
| `src/unique.rs` | Итератор, пропускающий повторения |
| `src/sort.rs` | Стабильная сортировка по убыванию модуля |
| `src/print_result.rs` | Трейт вывода и макрос `print_result!` |
| `src/cm_timer.rs` | Таймер на `Drop` и функция с замыканием |
| `src/process_data.rs` | Чтение и обработка вакансий |
| `src/bin/task1.rs` — `src/bin/task7.rs` | Примеры запуска |
| `STUDY.md` | Разделы книги для каждой задачи |

Модульные тесты находятся рядом с реализацией в блоках `#[cfg(test)]`.

## Принятые решения

- `field` заимствует входные данные и копирует только выбранные значения. Имена полей сохраняются внутри итератора.
- `Unique` хранит уже встреченные ключи в `HashSet`. Функция `unique_strings` задаёт режим сравнения строк. Для сравнения без учёта регистра применяется `to_lowercase`; нормализация Unicode и полное Unicode case folding не выполняются.
- Сортировка использует `unsigned_abs`, поэтому поддерживает `i32::MIN` без переполнения.
- Для демонстрации словаря используется `BTreeMap`, чтобы порядок вывода был определённым.
- Макрос `print_result!` вычисляет выражение один раз, выводит результат по ссылке и возвращает исходное значение.
- В `f2` после слова «программист» допускается конец строки или разделитель. Поэтому «Программист-разработчик» проходит фильтр, а «Программистка» и «Программист123» — нет.
- Таймер задачи 7 измеряет цепочку `f1`–`f4` вместе с выводом результатов. Чтение файла в это время не входит.
